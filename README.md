# Come to Me · Matthew 11:28

> *"Come to me, all you who are weary and burdened, and I will give you rest."*  
> — **Matthew 11:28**

A pure SVG, CSS, and vanilla JavaScript animated neon typography art piece. Amber, blue, white, and rose glass neon tubing with metal clips, ceramic electrode sleeves, and looping return wires mounted on a black fabric backdrop.

Originally designed and hosted on ChatGPT Sites (`neon-rest-matthew-1128`).

## Highlights

- **Pure Vector Centerline Lettering**: Custom single-stroke glyph geometry (`neon.js`) tracing the true centerline of bent glass neon tubes. No fonts, bitmap canvases, or photos are used for the letters.
- **Physical Details**: Realistic lead wires, metal mounting clips, electrode end fittings, and drop shadows creating physical depth off the backdrop.
- **Dynamic Lighting**: Layered SVG filters (`spill`, `halo`, `contact-shadow`) combined with CSS `@keyframes` animations simulating fluorescent tube warm-up flickers and subtle AC current fluctuations.
- **Fully Responsive**: Adapts seamlessly to mobile and desktop viewports (`svh`/`vw` units and media queries).
- **Zero Dependencies**: Vanilla HTML5, CSS3, and JavaScript with no external libraries or build steps.

## Local Development

Run any static HTTP server from this directory:

```bash
# Using Python
python3 -m http.server 8000

# Or using Node / npx
npx serve .
```

Open `http://localhost:8000` in any modern web browser.
